# Melaku Adane General Contractor

Corporate construction and civil-engineering website for Melaku Adane General Contractor.

## Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

## Current sections
- Hero / company positioning
- Services
- Featured projects
- Heavy machinery fleet
- Leadership
- Tender and contact
- English / Amharic content

## Run locally

```bash
npm install
npm run dev
```

## Production checklist

Before publishing, replace missing imagery with approved company photos and verify all company statistics, certifications, project claims, addresses, phone numbers, email addresses and leadership details.
